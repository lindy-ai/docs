## What is an Eval?

An eval is a way of measuring how well your agent is performing against a set of criteria. There are 2 types of evals:

- Offline evals use historical data to assess agent performance. It helps prevent regressions when an agent is edited. 
- Online evals use real-time data to assess agent performance. It helps monitor real-world performance and outputs of your agent. 

Currently, Lindy **only supports offline evals** for your agents, meaning you can monitor historical tasks that you specify and if they pass. Tasks will not be scored in real time. 

## Key Terminology

In Lindy, an **eval** is a reference task combined with a set of **scorers**. Typically, this is a task that has been performed well, so you can prevent regressions. Think of them as tests that you want to pass every time you deploy a new iteration of an agent. 

A **scorer** defines how the eval should be scored.

## Monitoring and Running your Evals

To monitor and run your evals, go to the evals tab. 

<Frame>
  <img
    src="/CleanShot2025-10-23at16.50.49@2x.png"
    alt="Auto mode intelligently filling email fields based on previous workflow data"
    style={{ borderRadius:"8px",border:"1px solid #e5e7eb" }}
    title=""

Here, can see a summary of all of your eval runs and the changes from the previous run. You can also see views for evals that have regressed (the score decreased) or have improved (score increased. 

<Info>
  Running an eval simply simulates how the run would behave with the current version of the agent. It will not execute actions. 
</Info>

<Info>
  Eval runs consume credits from your account.
</Info>
