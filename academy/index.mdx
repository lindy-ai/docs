Short videos that show how to set up Lindy and hand it your first tasks, in the order most people do them. Most run under a minute, and every page has the steps in text, so you can find them in search or ask the docs assistant.

Most of these set up your personal Lindy. For shared work, see [Meetings](/teammate/meeting-library), [Skills](/teammate/skills), and [Routines](/teammate/routines).

## Inbox

<CardGroup cols={2}>
  <Card title="Set up inbox triage" img="/lindy-brand-assets/academy/04-inbox.jpg" href="/academy/04-inbox">
    Turn on Email labeling and Email drafting, add a label, and build a weekday inbox routine. (1:08)
  </Card>
  <Card title="Get drafts that sound like you" img="/lindy-brand-assets/academy/05-voice.jpg" href="/academy/05-voice">

  </Card>
  <Card title="Set up your daily brief" img="/lindy-brand-assets/academy/06-brief.jpg" href="/academy/06-brief">

  </Card>
  <Card title="Get alerts for urgent emails" img="/lindy-brand-assets/academy/07-urgent.jpg" href="/academy/07-urgent">

  </Card>
  <Card title="Follow up on unanswered emails" img="/lindy-brand-assets/academy/08-bumps.jpg" href="/academy/08-bumps">

## Meetings

<CardGroup cols={2}>
  <Card title="Record and summarize meetings" img="/lindy-brand-assets/academy/09-notes.jpg" href="/academy/09-notes">

  </Card>
  <Card title="Get prepped before every call" img="/lindy-brand-assets/academy/10-prep.jpg" href="/academy/10-prep">

  </Card>
  <Card title="Schedule meetings without the back-and-forth" img="/lindy-brand-assets/academy/11-scheduling.jpg" href="/academy/11-scheduling">
