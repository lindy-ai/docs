A skill is a set of instructions Lindy can reuse for a job, like writing your weekly report, sorting your inbox, or preparing for customer calls. Write down what to do and when the instructions apply. Lindy can then use the skill when a request matches.

## Find your skills

Open **Skills** in the sidebar. If it isn't visible, expand **Customize**. Use **Personal** for your own skills and **Workspace** for skills shared with the workspace. Use **Search skills** to find one and switch between **Grid view** and **List view**.

## Create a skill

You can also teach a process by recording your screen or uploading a walkthrough. [Teach a task](/teammate/teach-a-task) helps you review the steps with Lindy and save them as a skill.

## Edit or share a skill

Open a skill you can manage and choose **Edit in Memory** to change its instructions. If you have permission to manage workspace skills, **Add to workspace** makes a personal skill available to the team.

Look under **Personal** for built-in skills. Open one to read what it does and select **Install** if you want to add it.

## How Lindy picks a skill

Lindy uses a skill's name and description to decide when to read its instructions. If it misses a skill you expected it to use, make the description more specific about the requests and tools it covers.
